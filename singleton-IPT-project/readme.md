# Singleton Pattern in PHP: IPT10 Midterm

Demonstration of the Singleton design pattern using PHP 8.1+.
Example: a shared portal configuration (`AufPortalConfig`) used by different modules.

## Requirements
- PHP 8.1 or higher

## How to run
```bash
php index.php
```

## Expected output
```
Same instance? Yes
School year seen by grades module: 2027-2028
```

## Files
- `src/AufPortalConfig.php`: the Singleton class
- `index.php`: demo script showing two modules sharing one instance
